# calcutils_twarimitswe

A simple student tutorial math utility package.

> **Note**: This is a test package from pip, not an actual real package.

## Installation

You can install this test package using `pip` (or `uv pip`) from TestPyPI:

```bash
# Using standard pip
pip install -i https://test.pypi.org/simple/ calcutils_twarimitswe

# Using uv (recommended)
uv pip install -i https://test.pypi.org/simple/ calcutils_twarimitswe
```

Alternatively, if installing directly from the source repository:

```bash
git clone https://github.com/twarimitswe/calcutils.git
cd calcutils
pip install .
```
